# Vigía · web

Web promocional de **Vigía**, centinela de seguridad para Windows: audita, vigila y refuerza tu propio PC desde un único panel, sin cuenta y sin que ningún dato salga del equipo.

Publicada en GitHub Pages: https://rootesq-pixel.github.io/vigia-web/

- HTML, CSS y JavaScript estáticos, sin compilación.
- Three.js 0.160 (radar 3D del hero, con fallback 2D sin WebGL), GSAP + ScrollTrigger, Lenis e iconos Lucide desde jsDelivr.
- Respeta `prefers-reduced-motion`.

## Activar las descargas

Edita `js/config.js`: revisa `url`, `file` y `size` de cada descarga y pon `available: true`.

Las capturas de img/app son reales (versión en desarrollo). La animación del índice y el mapa de conexiones son ilustrativos.
